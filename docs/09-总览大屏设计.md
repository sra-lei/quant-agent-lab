# 09 · 总览大屏设计（Dashboard）

> 状态：**设计稿 + 占位实现**。数据全部走 mock，接口契约先定死，后续按模块逐个接真实数据。
> 版本：v0.1 · 2026-11-13

---

## 0. 定位：这不是"数据罗列页"

总览要回答的是三个问题，且必须在一屏内答完：

1. **今天什么阶段？** —— 市场处在情绪周期的哪一档
2. **钱在往哪走？** —— 板块资金流向与强弱切换
3. **我该做什么？** —— 风险在哪、机会在哪、持仓怎么调

因此设计原则：

| 原则 | 含义 | 反面例子 |
|---|---|---|
| 结论先行 | 先给判断，再给支撑数据 | 上来就是 20 个涨跌幅数字 |
| 异常优先 | 极端值、背离、突变要主动跳出来 | 所有数据平铺，靠人自己找 |
| 一屏读完 | 1920×1080 主区不滚动 | 三屏滚动才能看完 |
| 缺数据要说话 | 没接的数据显示"未接入"，不显示 0 | 空图表被误读成"今天没有资金流入" |

**目标分辨率**：1920×1080（16:9）。1440 宽降级为两列堆叠，手机端不保证。

## 1. 布局：12 栅格

```
┌──────────────────────────────────────────────┬──────────────────┐
│ 模块一 · 全景态势图                    span 16 │ 模块六 · 持仓 8   │
│ 《战略要览》 + 阶段 + 情绪指数 + 核心矛盾      │ 盈亏/匹配度/建议   │
│ 高度 40%                                      │ 高度 40%          │
├───────────────┬───────────────┬──────────────┴──────────────────┤
│ 模块二 资金博弈 │ 模块三 情绪脉搏 │ 模块四 机会雷达        span 8×3 │
│    span 8      │    span 8      │                                │
│ 高度 32%       │ 高度 32%       │ 高度 32%                       │
├───────────────────────────────────────────────────────────────┤
│ 模块五 · 风险预警列表                                  span 24   │
│ 高度 28%，内部滚动                                             │
└───────────────────────────────────────────────────────────────┘
```

- 卡片圆角 8px，边框 1px（浅色主题 `#f0f0f0` / 大屏深色 `#1f2a3a`）
- 卡片间距 16px
- **A 股配色**：涨/流入 `#f5222d`（红），跌/流出 `#52c41a`（绿）——与欧美相反，不要用错
- 字号阶梯：12（辅助）/ 14（正文）/ 20（模块标题）/ 28（关键指标）/ 40（情绪指数）

**大屏模式**：右上角一个开关，切换为深色全屏（`#0b1220` 底），隐藏侧边栏与页脚，适合投屏。默认浅色，不做默认深色。

## 2. 六个模块

每个模块的契约都是同一形状，便于前端统一处理缺数据：

```json
{
  "status": "ok | degraded | missing",
  "source": "zvt | tdx_wenda | agent:planner | manual",
  "as_of": "2026-11-13 15:35",
  "note": "缺失原因（status != ok 时必填）",
  "data": { }
}
```

### 模块一 · 全景态势图

**目的**：一屏之内说清"现在是什么局面"。

| 元素 | 内容 | 数据来源 |
|---|---|---|
| 《战略要览》 | 总调度智能体（`planner`）输出的 120–200 字判断，含"怎么做、不做什么" | `agent:planner` 最近一次 run |
| 市场阶段 | 冰点 / 修复 / 发酵 / 高潮 / 退潮（五档） | 情绪指数分档规则 |
| 综合情绪指数 | 0–100，附今日 vs 昨日、5 日趋势箭头 | `zvt` 合成 |
| 核心矛盾 | 一句话 + 两个支撑数据点 | `agent:planner` |
| 更新时间 | 数据截止时间 | — |

```json
{
  "status": "ok",
  "source": "agent:planner",
  "as_of": "2026-11-12 15:35",
  "data": {
    "brief": "情绪从高位回落，连板高度卡在 5 板，指数缩量但涨停家数没崩，属于退潮中的抵抗。今天不追高位接力，只做低位首板的确认。",
    "phase": { "key": "ebb", "label": "退潮", "since": "2026-11-12", "days": 1 },
    "sentiment_index": { "today": 42.6, "yesterday": 58.1, "delta": -15.5, "trend_5d": "down" },
    "core_conflict": {
      "text": "指数缩量下跌 vs 连板高度仍在 5 板",
      "evidences": [
        { "label": "成交额", "value": "1.60 万亿", "change": "-11.3%" },
        { "label": "涨停家数", "value": 37, "change": "-45/日" }
      ]
    }
  }
}
```

**降级**：planner 没跑过 → `status: "missing"`，显示"今日尚未生成战略要览，点这里运行"，其余三项仍可展示（它们只依赖行情）。

### 模块二 · 资金博弈图

**目的**：看清钱在哪些板块之间搬家。

**首版**（本期）：净流入 Top5 / 净流出 Top5 的横向条形对比 + 板块涨跌幅。

**二期**：桑基图（`资金从 A 板块流向 B 板块`），需要板块间的联动估算，成本高，先不做。

```json
{
  "status": "ok",
  "source": "akshare:board_fund_flow",
  "as_of": "2026-11-12 15:35",
  "data": {
    "net_inflow_top": [
      { "board": "光伏设备", "net_inflow_yi": 38.4, "change_pct": 2.31, "leader": "亚玛顿" },
      { "board": "银行", "net_inflow_yi": 21.7, "change_pct": 0.84, "leader": "招商银行" }
    ],
    "net_outflow_top": [
      { "board": "半导体", "net_outflow_yi": 46.2, "change_pct": -2.14, "leader": "中芯国际" }
    ],
    "note": "净流入以主力净额计，不含散户小单"
  }
}
```

**现状**：板块资金流接口**尚未接入**（本地 zvt 库的 `block_money_flow` 为 0 行）。本期用 mock，`status: "degraded"` + `source: "mock"`。

### 模块三 · 情绪脉搏图

**目的**：像心电图一样看出情绪的"心跳"——什么时候加速、什么时候骤停。

| 元素 | 内容 |
|---|---|
| 主图 | 近 60 个交易日情绪指数折线，叠加 20 日均值虚线带 |
| 极端点 | 偏离均值 > 1.5σ 的日期打红/绿点 |
| 极端个股/板块 | 今日处于极端区的标的（≥5 板、跌停、连板断层） |

```json
{
  "status": "ok",
  "source": "zvt",
  "as_of": "2026-11-12",
  "data": {
    "series": [
      { "date": "2026-11-10", "value": 63.2 },
      { "date": "2026-11-11", "value": 58.1 },
      { "date": "2026-11-12", "value": 42.6 }
    ],
    "ma20": 55.4,
    "extremes": [
      { "type": "stock", "code": "600327", "name": "大东方", "reason": "5 连板，情绪最高标", "side": "hot" },
      { "type": "board", "code": "BK0477", "name": "半导体", "reason": "主力净流出 46 亿", "side": "cold" }
    ]
  }
}
```

**情绪指数口径**（P1 实现，需写死避免各模块各算一套）：

```
情绪指数 = 100 × (0.35×涨停家数分位 + 0.25×封板率 + 0.20×最高连板分位 + 0.20×涨跌家数比)
每一项先做 60 日滚动 min-max 归一，缺失项按权重重分配
```

### 模块四 · 机会雷达图

**目的**：一眼看出"现在什么风格占优"，以及系统推荐的具体方向。

**雷达 5 轴**（每轴 0–100）：

1. 题材热度 —— 板块内涨停家数、讨论度
2. 资金强度 —— 板块主力净流入分位
3. 赚钱效应 —— 板块内上涨家数占比
4. 持续性 —— 板块连涨天数 / 5 日涨幅稳定性
5. 拥挤度 —— 换手率分位（越高越拥挤，作为反向指标展示）

两个多边形：**今日** vs **5 日均值**，对比看风格漂移。

右侧列出策略智能体推荐方向（2–3 个标签 + 置信度 + 一句话理由）。

```json
{
  "status": "ok",
  "source": "zvt + agent:strategy",
  "as_of": "2026-11-12",
  "data": {
    "axes": ["题材热度", "资金强度", "赚钱效应", "持续性", "拥挤度"],
    "today": [72, 41, 38, 55, 66],
    "ma5": [65, 58, 62, 60, 48],
    "picks": [
      { "direction": "低位首板确认", "conviction": 0.72, "reason": "高位断层，资金转向低位补涨" },
      { "direction": "光伏设备", "conviction": 0.61, "reason": "净流入连续 3 日居前" }
    ]
  }
}
```

**现状**：板块维度数据未接入，本期 mock。

### 模块五 · 风险预警列表

**目的**：把"会亏钱的事"顶到眼前。**只列有依据的，不列套话。**

| 字段 | 说明 |
|---|---|
| 级别 | `high`（橙红）/ `medium`（橙）/ `low`（黄） |
| 标题 | ≤20 字，说清楚是什么风险 |
| 依据 | 一句话，带数字 |
| 来源 | 哪个智能体/规则产生的 |
| 时间 | 首次发现时间 |

```json
{
  "status": "ok",
  "source": "agent:reviewer + rules",
  "as_of": "2026-11-12 15:35",
  "data": {
    "items": [
      { "level": "high", "title": "高位股进入亏钱效应", "evidence": "5 板以上个股次日平均 -6.2%，连续 2 日", "source": "规则:连板断层", "time": "2026-11-12 15:05" },
      { "level": "medium", "title": "封板率跌破 50%", "evidence": "37 涨停 / 42 炸板 = 46.8%", "source": "zvt", "time": "2026-11-12 15:05" }
    ]
  }
}
```

**展示**：列表内部 60s 自动轮播滚动；鼠标悬停暂停。数量超过 8 条时只显示前 8 条 + "查看全部"。

**规则引擎**（P1，先写死几条，不靠模型）：

- 涨停家数较昨日下降 > 50% → high
- 封板率 < 50% → medium
- 最高连板数断层（从 ≥5 掉到 ≤3）→ high
- 单日跌幅 > 7% 的个股数 > 200 → high

### 模块六 · 个人持仓仪表盘

**目的**：把自己的钱和上面五个模块的结论对齐。

| 元素 | 内容 |
|---|---|
| 汇总 | 总盈亏（金额 + 百分比）、当日盈亏、与热点匹配度 0–100 |
| 持仓表 | 代码 / 名称 / 成本 / 现价 / 盈亏% / 仓位% / 所属热点 |
| 调仓建议 | 每只股一条：加仓 / 减仓 / 持有 / 止损，附理由与触发条件 |

**匹配度口径**：

```
匹配度 = 仓位加权后的「持仓股所属板块出现在今日净流入 Top10 的占比」× 100
```

```json
{
  "status": "degraded",
  "source": "manual",
  "as_of": "2026-11-12 15:35",
  "note": "持仓为手工占位数据，尚未接入真实账户",
  "data": {
    "summary": { "total_pnl": 8420.5, "total_pnl_pct": 4.21, "today_pnl": -1230.0, "match_score": 62 },
    "positions": [
      { "code": "600519", "name": "贵州茅台", "cost": 1350.0, "price": 1410.27, "pnl_pct": 4.46, "weight": 32, "hot_board": "食品饮料" }
    ],
    "advices": [
      { "code": "600519", "action": "hold", "reason": "板块不在资金流入前列，但持仓成本低，不主动加仓", "trigger": "跌破 1350 减半" }
    ]
  }
}
```

**红线**：

- 持仓数据**只存本地**，不上传任何第三方
- 系统**只给建议，不接券商、不下单**
- 未导入持仓时显示引导，不显示伪造的盈亏

## 3. 聚合接口

一个请求返回六块，避免首屏 6 个并发请求互相拖慢：

```
GET /api/dashboard?date=2026-11-12&portfolio_id=default
```

```json
{
  "as_of": "2026-11-12",
  "generated_at": "2026-11-13T15:35:12+08:00",
  "mock": true,
  "modules": {
    "panorama":    { "...模块一" },
    "capital_flow":{ "...模块二" },
    "sentiment":   { "...模块三" },
    "opportunity": { "...模块四" },
    "risks":       { "...模块五" },
    "portfolio":   { "...模块六" }
  }
}
```

**为什么单接口**：大屏是"一眼看完"的场景，六块数据必须**同一时刻**的快照；分开请求会出现"资金流是 15:30 的、情绪是 15:35 的"这种时间错位。

**性能目标**：单次 < 800ms（P0 全 mock，P1 接 zvt 后需实测）。

## 4. 数据来源与缺口

| 模块 | 现在能算吗 | 缺什么 | 补法 |
|---|---|---|---|
| 一 · 战略要览 | 需 planner 跑过 | 无（模型输出） | 定时跑 planner |
| 一 · 市场阶段/情绪指数 | ✅ 可算 | — | zvt 合成 |
| 二 · 资金博弈 | ❌ | 板块资金流 | akshare 板块资金流接口（待验证） |
| 三 · 情绪脉搏 | ✅ 可算 | — | zvt 合成 60 日序列 |
| 三 · 极端个股 | ✅ 可算 | — | zvt.limit_board |
| 四 · 机会雷达 | ⚠️ 部分 | 板块热度、板块换手 | 板块行情（akshare） |
| 五 · 风险预警 | ⚠️ 部分 | 规则引擎未写 | 先写 4 条硬规则 |
| 六 · 持仓 | ❌ | 账户数据 | 手工录入 / CSV 导入 |

## 5. 分期计划

| 阶段 | 内容 | 产出 |
|---|---|---|
| **P0（本期）** | 契约定死 + 六模块占位 UI + 全 mock 数据 | 能看、能评审布局 |
| **P1** | 模块一（情绪指数/阶段）、模块三（脉搏图）、模块五（4 条规则）接 zvt | 三个模块真实数据 |
| **P2** | 模块二（板块资金流）、模块四（雷达）接 akshare | 资金与风格可看 |
| **P3** | 模块六 持仓导入（CSV / 手工） | 个人化 |
| **P4** | 大屏模式：深色全屏、自动刷新 60s、轮播 | 投屏可用 |

## 6. 验收标准

- [ ] 1920×1080 主区不滚动，六模块全部可见
- [ ] 任一模块数据缺失时显示明确占位（"未接入"/"今日未生成"），**绝不显示 0 或空图**
- [ ] 每个数字可追溯：悬停能看到 `source` 与 `as_of`
- [ ] 红涨绿跌，不出现颜色反用
- [ ] 首屏加载 < 1.5s（mock 阶段）
- [ ] 持仓模块在未导入时显示引导，不显示示例盈亏
