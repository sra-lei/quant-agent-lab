# 05 · 路线图

## v0.1 — 地基（当前）

**目标**：接口、契约、数据流定型；任何人 clone 下来能跑通一次完整研究（Mock 数据）。

- [x] 需求文档 / 架构文档 / Agent 契约 / 数据源接入文档
- [x] FastAPI 骨架（runs / signals / strategies / reviews / health）
- [x] 五个 Agent 的类与契约（业务逻辑为最小可用版）
- [x] `SimpleOrchestrator`（可跑）+ `LangGraphOrchestrator`（骨架，可选依赖）
- [x] `MockProvider`（默认）
- [x] 前端页面骨架（总览 / 策略 / 信号 / 运行轨迹 / 复盘）
- [x] 智能体编辑器（名称/角色/工作流/工具/输出格式 + 试运行）
- [x] 提示词与配置版本历史（差异对比 + 回滚）
- [x] 工具执行层（8 个工具的真实 handler + function calling 循环）
- [ ] 通达信 MCP 适配器（接口已留，需真实 endpoint 联调）

**验收**：`POST /api/runs` 能返回一份含分歧标注的结论，前端能看到运行轨迹。

## v0.2 — 真实数据与分析

**目标**：接真实数据，两个分析师给出经得起看的结论。

- [ ] `TdxMcpProvider` 完整实现（行情/K线/公告/板块）
- [ ] **自定义 Agent 接入日常编排**（ConfigDrivenAgent 实现 BaseAgent + plan 读取启用的配置）
- [ ] 工作流分支（步骤间条件判断，如"数据缺失则跳过该分析师"）
- [ ] 数据落库与缓存（按 as_of 分片）
- [ ] 价投专家：PE/PB 分位、ROE 趋势、现金流质量三维打分
- [ ] 游资专家：连板高度、炸板率、主力净流入、换手率异常
- [ ] 前端信号详情页：推理链 + 数据溯源跳转
- [ ] 定时任务：盘后自动运行

**验收**：连续 5 个交易日无人值守运行，数据缺失率 < 5%。

## v0.3 — 复盘闭环

**目标**：系统会从错误里学。

- [ ] 观察员：按真实行情回算命中率/收益/回撤
- [ ] 归因模型：区分「数据问题 / 逻辑问题 / 执行问题」
- [ ] 权重回灌：按 Agent 历史命中率调整其在合并时的权重
- [ ] 周报自动生成与推送

**验收**：能说清"上周为什么错"，且给出的改进项在下一周可验证是否执行。
