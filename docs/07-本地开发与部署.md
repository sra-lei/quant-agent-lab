# 07 · 本地开发与部署

## 1. 后端

```bash
cd backend
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e .                                       # 装 [langgraph] 可选：pip install -e ".[langgraph]"
cp ../.env.example ../.env                             # 按需修改
uvicorn app.main:app --reload --port 8000
```

- 接口文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/api/health（会显示当前数据源与编排器）
- 冒烟测试（不联网、不花钱）：

```bash
python scripts/smoke.py
```

## 2. 前端

```bash
cd frontend
npm install
npm run dev        # http://127.0.0.1:5173，已配置 /api 代理到 8000
npm run build      # 产物在 dist/
```

## 3. 切换到 LangGraph 编排

```bash
pip install -e ".[langgraph]"
export ORCHESTRATOR=langgraph
```

未安装时会**自动降级**为 `SimpleOrchestrator` 并在日志里提示，服务不会起不来。

## 4. 接入真实数据

### 通达信（免费，主源）

```bash
pip install tdx-mcp
tdx-mcp --port 8100
```

```env
DATA_PROVIDER=tdx_mcp
TDX_MCP_ENDPOINT=http://127.0.0.1:8100
```

### Wind（本机 Windows，复用终端额度）

```bash
git clone https://github.com/abuttoncc/wind-mcp
cd wind-mcp && pip install -r requirements.txt
python src/wind_mcp_direct_server.py --host 0.0.0.0 --port 8888
```

```env
WIND_MCP_ENDPOINT=http://<windows-ip>:8888
```

**安全**：Wind 密钥不要上传云端；跨网访问请走隧道（frp / cloudflared）并限制来源 IP。

## 5. Docker

```bash
cd deploy
cp ../.env.example .env
docker compose up --build
```

- 前端：http://localhost:5173
- 后端：http://localhost:8000/docs

## 6. 测试

```bash
cd backend
pip install -e ".[dev]"
pytest -q
```

契约测试重点验证三件事：DAG 合法性、**分歧不被平均**、缺失数据不被填 0。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `/api/health` 显示 degraded | 数据源不可达 | 检查 MCP endpoint；或切回 `DATA_PROVIDER=mock` |
| 结论里 `risk_notes` 提到 mock | 用的是演示数据 | 正常；接真实源后消失 |
| 前端 404（刷新后） | 直接访问子路由 | nginx 已配 `try_files`；开发用 vite 即可 |
| LangGraph 未生效 | 未安装或未设环境变量 | 见第 3 节，日志会有降级提示 |
