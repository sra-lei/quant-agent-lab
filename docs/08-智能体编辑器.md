# 08 · 智能体编辑器

> 前端 `/agents` 页面：新建与编辑智能体，包含名称、角色描述、工作流、可用工具、输出格式。

## 1. 配置模型

| 字段 | 类型 | 说明 |
|---|---|---|
| `agent_id` | string | 主键。内置为固定值（如 `value_analyst`），自定义为 `custom_<hash>` |
| `name` | string | 展示名，≤80 字 |
| `role` | text | **角色描述**：身份、职责、边界，会作为系统提示词的主体 |
| `workflow` | `[{name, instruction}]` | **工作流**：有序步骤，每步一句可执行指令 |
| `tools` | `string[]` | **可用工具**：必须来自工具注册表 |
| `output_format` | `{type, schema?}` | **输出格式**：`json_schema` / `markdown_table` / `text` |
| `enabled` | bool | 停用后不参与未来的流程编排 |
| `builtin` | bool | 系统预置，可编辑不可删除 |

## 2. 三条设计约束

### 2.1 工具必须来自注册表
不允许自由填字符串。填了不存在的工具，运行时才炸——这种错误不该留到运行阶段。
注册表在 `backend/app/agents/tools.py`，新增工具加一条即可，前端下拉框自动出现。

### 2.2 内置智能体可编辑但不可删
`builtin=true` 的条目（收集员/价投/游资/规划官/观察员）可以被改提示词、加步骤、换工具，
但不允许删除，`agent_id` 也不允许改——否则编排计划里的引用会断。

### 2.3 保存前可试运行
编辑器右上角「试运行」会真正执行一遍：

```
配置 → 拼装提示词（角色 + 工作流 + 工具 + 输出要求 + 输入）
     → LLM 生成
     → 按 output_format 校验
     → 返回结果与校验状态
```

**没有配置 LLM Key 时**：返回按 schema 生成的结构样例，并明确标记 `mock: true`，
前端显示黄色提示条。不会假装那是真实推理结果。

## 3. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/agents/meta` | 工具清单、输出格式预设、默认 schema |
| GET | `/api/agents` | 列出全部智能体 |
| GET | `/api/agents/{id}` | 单个详情 |
| POST | `/api/agents` | 新建（自动生成 id） |
| PUT | `/api/agents/{id}` | 全量更新 |
| DELETE | `/api/agents/{id}` | 删除（内置返回 400） |
| POST | `/api/agents/{id}/run` | 试运行，body: `{"input": {...}}` |

## 4. 输出格式与校验

`json_schema` 模式使用**自带的极简校验器**（`config_agent._validate`），支持：

`type` / `required` / `properties` / `items` / `enum` / `minimum` / `maximum`

**为什么不引入 jsonschema 库**：开源用户不该为了一个校验器多装一个依赖，
而以上关键字已覆盖本项目全部用例。需要完整 JSON Schema 时可替换实现，
校验函数的签名保持不变。

## 5. 与编排的关系（当前边界）

v0.1 里，编辑器保存的配置用于：**持久化 + 试运行**。
内置的 5 个 Agent 仍由代码实现（确定性规则，可回测、可审计）。

自定义智能体接入日常流程（`POST /api/runs`）属于 v0.2，需要补两件事：

1. `TaskPlan` 生成时读取 `enabled=true` 的自定义 Agent
2. `ConfigDrivenAgent` 实现 `BaseAgent` 接口，接入 registry

这两步不改变契约，只增加一个 Agent 实现，风险可控。

## 6. 后续可加的能力（按优先级）

| 能力 | 价值 |
|---|---|
| 工作流 DAG 可视化（拖拽） | 表达"先 A 后 B、B 失败则走 C"的分支 |
| 提示词 diff 与版本历史 | 改坏了能回滚，能对比两次改动的效果 |
| 配置导入/导出（JSON / Git） | 团队共享，或作为 profile distribution 分发 |
| 工具参数级配置（不只选工具，还能设默认参数） | 减少每次运行时的重复设置 |
